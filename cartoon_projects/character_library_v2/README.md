# مجموعتا شخصيات الكرتون

20 نموذجاً: عشرة أدوار في أسلوب الرأس الكبير ذي الألوان المسطحة والحدود السميكة، والعشرة نفسها في أسلوب الرسم الخطي البسيط. جميع الشخصيات بلا ملامح وجه. الصور المرجعية محفوظة في `references/` للدراسة؛ لا تستخدم كأصول داخل الرسوم أو المعاينة.

## الاستخدام

```ts
import {drawCharacter,characters} from './rig';
const actor = characters.find(c => c.id === 'elder')!;
drawCharacter(ctx, actor, frame / fps, 'explain', x, floorY,
  'rounded', {scale: 1.5, flip: false});
// استبدل rounded بـ line لاستخدام المجموعة الثانية.
```

الجذر عند الأرض، و`scale` يُضرب بمقياس طول الشخصية. الحركات الثماني: `idle`, `listen`, `explain`, `point`, `wave`, `carry`, `walk`, `sit`. جميع المفاصل والعناصر تُحسب من الزمن المطلوب بلا حالة متراكمة. لا حاجة لتنزيل نموذج ذكاء اصطناعي أو برامج إضافية.

الأطراف والأيدي متصلة بنقاطها؛ أبعاد العظام مختلفة بين الأسلوبين. في المشي تنتقل الشخصية إلى الأمام مع تثبيت القدم أثناء الارتكاز. الجلوس يتضمن مقعداً تجريبياً، والحمل يتضمن وضعية صندوق ممسوك باليدين. عند تركيب مشهد حقيقي يُستبدل المقعد أو العنصر مع المحافظة على نقاط التماس. الانتقال بين حركتين في لقطة متصلة يحتاج توقيتاً ومزجاً مقصودين، وليس تبديل اسم الحركة فجأة. الشرح إيماءة عامة، ويجب توقيته مع جمل المتحدث الفعلية.

## الملفات

- `assets/rounded/lineup.png`: المجموعة الأولى.
- `assets/line/lineup.png`: المجموعة الثانية.
- داخل مجلد كل مجموعة: أربع وضعيات PNG شفافة لكل شخصية (وقوف، شرح، حمل، جلوس)، بمقاس 640×800، بالإضافة إلى معاينة حركة عمودية قصيرة `motion-preview.mp4`.
- `catalog.ts`: الأسماء العربية والألوان والأعمار والملابس. `manifest.json`: فهرس النماذج والحركات. `rig.ts`: الرسم والمفاصل.
- `QA.json` و`review/ui-checks.json`: فحوص حسابية وواجهة؛ لا تستبدل المراجعة الفنية للحركة.

المعاينة: `node cartoon_projects/character_library_v2/serve.mjs` ثم http://localhost:3306 . تتحرك شخصية واحدة فقط، ويتوقف الرسم عند إخفاء الصفحة، والحد المستهدف للمعاينة 30 إطاراً/ثانية.

هذه رسوم أصلية مأخوذة من الصفات العامة للأسلوبين، ولا تستخدم الشخصية المرفقة أو علامتها المائية كعنصر في الفيلم. كود الرسم جديد، ويستخدم دالة المفاصل العامة `ik` من Papermotion برخصة MIT المحفوظة في `LICENSE.papermotion`. الإصدار السابق مستقل ومحفوظ.
