# حوار الأعمال والرحمة

18 مشهداً مرقماً بصيغة SVG مستقلة، 1080×1920، برسوم متجهية وطبقات مسماة. أسلوب Illustration؛ لا تعتمد الحزمة على برنامج Illustrator.

الطبقات: الخلفية والأثاث، جسم كل شخصية، الذراع اليمنى، الذراع اليسرى، الفم، اللوحات، النصوص، الكابشن. النماذج من مكتبة عائلة أبو خط الدائمة دون إعادة رسم الوجوه.

كل SVG يحتوي الخطين محلياً مضمّنين ويحتفظ بالنصوص العربية قابلة للتحرير. التوقيت والحركات المتصلة في scene.ts، والجدول والكلمات في timing.json. تُشغَّل الحركة من تركيبة Remotion AqndDialogue18. ملفات SVG لقطات مفصلية قابلة للتحرير وليست فيديوهات مستقلة.

الصوت من النسخة المرسلة بلا موسيقى؛ قُصّرت فترات الصمت الطويلة إلى نحو 0.25 ثانية دون حذف أي كلمة منطوقة، وأُعيد ضبط توقيت المشاهد والكابشن وفق ذلك. الكلمات غير المؤكدة عند 6.06–6.48 و8.34–9.58 ثانية لا تُعرض.

الآيات: قاعدة quran-uthmani المحلية، مطابقة لبوابة دين الحق: https://din.hk/tafseer?sura=3&aya=132 وhttps://din.hk/tafseer?sura=24&aya=56.
