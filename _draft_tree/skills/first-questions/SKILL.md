# الأسئلة الأولى وبدء التجهيز

## 1) قبل السؤال مباشرة (في الخلفية)
`node tools/stage.mjs prep <المشروع> "<الفيديو>"` — ينسخ الأصل، ويسجّل المونتاج وقائمة مهامه، ويبدأ التفريغ (مهارة `transcription`). لا أنتظر الأجوبة لأبدأه.

## 2) الأسئلة (بالنقر، دفعة واحدة، أول فعل)
1. **العنوان:** ثلاثة مقترحات، **أحدها العنوان الأصلي** (اسم ملف الفيديو الذي أرسله بلا الامتداد). المقترحان الآخران بشروط العنوان في `thumbnail-design` (سؤال أو صدمة أو فضول، صادق، ≤ 99 حرفاً).
2. **مقاطع مضافة (B-roll):** نعم / لا (مقاطع فيديو منزَّلة فقط؛ الصور والقصاصات والعناصر دائمة بلا سؤال).
3. **الصيغ** (اختيار متعدد): عرضي / طولي كامل / ريل. ما لم يُختر لا يُبنى ولا يُرندر.
4. **أين يُرفع كل صيغة اختارها** (يظهر سؤال الصيغة فقط إن اختارها):
   - العرضي: القناة الأساسية (محمد بن شمس الدين) أم «الردود العلمية»؟ (الموضوع العام للأساسية، والرد على أحد للردود).
   (جواب المستخدم 2026-11-17: أسأل كل مرة، والغالب محدد مسبقاً فينقر فقط.)
   - الطولي الكامل: درايف «انستا وفيس» (المستحسن، الغالب) أم «الكل»؟
   - الريل: درايف «الكل» (المستحسن، الغالب) أم «انستا وفيس»؟
5. **يوتيوب** (إن اختار العرضي): نشر مباشر أم جدولة؟ وإن اختار الجدولة: **اليوم والساعة هنا مع الأسئلة الأولى** (جواب المستخدم 2026-11-17)، لا عند الاعتماد. قبل اعتماد الموعد: `node tools/publish_schedule.mjs` (لا فيديوان في يوم واحد في القناة نفسها).

## 3) لا يُسأل عنه
المجلد المحلي، اتجاه الكرتون والتعليق الصامت والمونتاج الورقي (طولي دائماً)، الصور والقصاصات والعناصر (دائمة)، أوك (منشور دائماً لما يُرفع عدا الموشن والكرتون)، شريك قناة «الردود العلمية» (دائم).

## 4) تسجيل الأجوبة
تُكتب الأجوبة في `.tmp/<المشروع>/answers.json` (العنوان، الصيغ، وجهة كل صيغة، النشر/الجدولة) فتقرؤها مهارتا `approval` و`publishing` بلا سؤال ثانٍ، ثم `montage_guard stage <المشروع> questions --skill first-questions --done "…"`.
الأداة: `node tools/answers.mjs set <المشروع> <المفتاح> "<القيمة>"`، والقراءة `get`، والتحقق قبل النشر `need <المشروع> مفتاح1,مفتاح2`.

## 5) بعد الأجوبة
لا أسئلة حتى النهاية إلا لعائق حقيقي؛ التأكيدات (صورة فلان، خطأ آية، رقم مختلف فيه، عزو حديث، كلمة «مونتاج» مشكوك فيها) في صفحة الأسئلة (`node tools/questions.mjs add …`) والعمل مستمر.

## بوابة المهارة
تمّ = الأجوبة الخمسة مسجّلة في ملف المشروع (وما لا يخص الصيغ المختارة متروك)، والتجهيز يعمل، والموعد إن وُجد لا يتعارض مع غيره.
