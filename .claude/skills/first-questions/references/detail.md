# التفصيل (منقول بنصه من ملف التفصيل القديم عند تثبيت الشجرة، 2026-11-17)

> ملزم كالمهارة نفسها. عند التعارض مع نص المهارة المكتوب في 2026-11-17 فما في المهارة أحدث.

### 2) الأسئلة
- **أين يُرفع:** الموضوع العام ← القناة الأساسية @MShmsDin، والرد ← «الردود العلمية»؛ الجواب لا يُفترض ويحدّد قناة حزمة يوتيوب.
- **صفحة الأسئلة:** `node tools/questions.mjs add <p> --id … --q … [--img …] [--video <مقطع> --t0 --t1] [--link …] [--opts "أ|ب"]`؛ الخادم `questions.mjs serve` (3110) في لوحة المعاينة وبرابط IP الشبكة؛ الأجوبة `questions.mjs answers <p>`.
- **جواب المقاطع المضافة (أمر المستخدم 2026-11-18):** «نعم» = كل مقطع مضاف (B-roll) مناسب يُضاف بلا سؤال بعد أن أنظره بنفسي (لا نساء غير مطموسات، ويطابق المعنى المنطوق)؛ «لا» = لا مقاطع فيديو مضافة في هذا الفيديو، وتبقى الصور والقصاصات والعناصر كما هي.
- **اختلاف الأرقام:** كل بند مختلف مرقّماً بخياراته وقرار لكل بند؛ ما لا يُختار يبقى كما نطقه مع رابط المصدر.
- **الريلز:** «القصة» (ادعاء ← حجة ← خلاصة) وجدول المحذوف/المُبقى يُعرضان قبل البناء.
- **الفيديو القصير (أمر المستخدم 2026-11-18):** فيديو نحو 7 دقائق: «أنبّه المستخدم ليرسل لي ما أضيفه»؛ لا أضيف شيئاً من عندي.
- **صفحة الأسئلة (أمر المستخدم 2026-11-18):** لا يُسأل فيها عن كلمة «مونتاج»، تُحسم بالسياق (مهارة `montage-orders`). كل جواب جديد يأتي معه تنبيه، وفحص المرحلة يرفض جواباً لم يُطبَّق؛ وأداة الصفحة تشغّل خادمها بنفسها وتختبر الرابط قبل إرساله؛ والصفحة تحفظ الملاحظات بنفسها (تمّ 2026-11-18).
