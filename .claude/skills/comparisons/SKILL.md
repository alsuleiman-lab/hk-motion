# مهارة المقارنات

- حدّد طرفي المقارنة ومعيارها ووحدتها والفترة الزمنية قبل تصميم المشهد.
- اعرض العناصر بترتيب مفهوم وبمقياس صادق؛ لا توحِ بمقارنة غير متكافئة.
- اربط كل رقم أو ادعاء بمصدر ظاهر أو رابط قابل للقراءة. إذا اختلفت الأرقام، اعرض كل بند مرقماً واطلب قرار المستخدم قبل تغييره؛ غير المحسوم يبقى كما نُطق مع رابطه.
- أضف صورة أو علماً أو غلافاً أو شعاراً لكل كيان مذكور بحسب نوعه.
- اجعل النص مقروءاً والخلفية داكنة مزخرفة أو صورة مناسبة غير سوداء، وافحص التباين والوجوه والحواف.
- استخدم رسوم `motion-graphics` عند الحاجة، مع ظهور كل عنصر عند ذكره.
