The user's examples illustrate a METHOD; they are not a feature list. On 2026-11-20 he had given «سجن، ماء، ضيق، رجفة» as examples of using the background to express meaning instead of adding pictures. A readiness audit turned them into a to-do list, and I built fixed `squeeze`/`water` effects plus a word→effect lexicon. He corrected it: «أنا ما قلت تضيف الماء والتضييق… ذكرتها كأمثلة على أنك تبتكر… هذه ليست مؤثرات ثابتة، هذه طريقة تفكير».

**Why:** fixed menus kill the invention he wants. Each moment should get its own idea, chosen when it is needed.

**How to apply:**
- When a user message lists examples after «مثلاً»/«يعني»/«لما أذكر…», capture the principle in the relevant skill. Do not build each example as a feature.
- If unsure whether he means the examples literally, ask in one line before building.
- Audit agents must not turn examples into requirements.
