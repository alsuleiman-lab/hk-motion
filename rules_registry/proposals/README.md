# مقترحات تعديل القواعد (من الجلسات غير المسؤولة)
الجلسة المسؤولة وحدها (المعيَّنة من المستخدم 2026-10-23: جلسة «تصحيح الحديث بالكشف الصوفي» التي أنشأت السجل) تعدّل `rules_registry/*.md`.
أي جلسة أخرى ترى خطأً أو قاعدة جديدة أو تعارضاً تكتب **ملفاً جديداً هنا** باسم `YYYY-MM-DD_<الجلسة>_<موضوع>.md` فيه:
1. الرقم المقصود (أو «قاعدة جديدة») 2. النص المقترح 3. السبب (أمر المستخدم بتاريخه أو الحادثة) 4. ما يتعارض معه من النصوص القائمة.
لا تكتب فوق ملف قائم، ولا تعدّل `PREFERENCES.md` أو غيره من القواعد بسبب مقترحك قبل اعتماد المستخدم.
