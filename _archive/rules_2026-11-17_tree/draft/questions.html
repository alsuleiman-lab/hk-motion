اختر جواباً لكل سؤال، واكتب ملاحظة إن شئت، ثم «احفظ». كل جواب يصلني فوراً وأعدّل المسوّدة به. الخيار المعلَّم «المستحسن» هو رأيي.

شجرة العمليات المختصرة (للرجوع إليها) 
٠ الموجّه ← ١ الأسئلة الأولى + التجهيز ← ٢ التفريغ (مرة واحدة، أقوى نموذج، بالمتحدثين)
← ٣ الاستخراج قبل القص: كتل «مونتاج» بمراسيها + «عفواً/أعيد» + الكلمات الحساسة
← ٤ القص (نموذج القص الواحد) ← ٥ الاستخراج بعد القص: أسماء، آيات، أحاديث، أخبار، حلقات سابقة، أقسام الفيديو
← ٦ الهوية: لون، فاصل، شريط الحلقة ← ٧ الغلاف ← ٨ الخطة والبناء من المعرض
← ٩ الفحص السريع ← ١٠ روابط المراجعة ← ١١ الرندر بالطابور ← ١٢ الاعتماد والنشر
وفي أي وقت: قص جزء محدد بين كلمتين.
