Before asking the user for a fact (which episode, which link, which source), search for it myself with what is already there: the text written in the element, YouTube search, the channel index, oEmbed.

**Why:** 2026-11-20, I asked him for the right short about the Jordan mufti while the search bar element already held its words; one YouTube search found it («مفتي الأردن يرد حديث رسول الله», 9EwclFjjUzk). He: «انت لازم تعرفه»، «لا تكن كسولا».

**How to apply:** ask only after the searches fail, and say what I searched. The channel index (data/channel/episodes.json) can be a day old: search YouTube for new videos. Related: [[fix-first-then-investigate]].
