# الموجّه

> قبله: `00_القواعد_العامة.md`. بعده: `01_شجرة_العمليات.md` ثم مهارة كل مرحلة حين تصلها.

## الطلب ← السلسلة
| ما يقوله المستخدم | السلسلة |
|---|---|
| فيديو يُرسل وحده، أو «اعمل مونتاج لهذا الفيديو» | شجرة العمليات كاملة (حلقة عادية) |
| «ريل» / «ريلز» من فيديو | شجرة العمليات، صيغة الريل (طولي 9:16) |
| «الدرس الأخير» / «البث الأخير» | `lessons-and-streams` (تجلب أحدث تسجيل من مجلد الفيديو بنفسها: `node tools/latest_recording.mjs lesson` أو `stream`) |
| رابط درس أو بث | `lessons-and-streams` بلا أسئلة |
| «كرتون» / «دودو» / «أبو خط» | `cartoon-animation` |
| «خذ هذا الفيديو وعدّله واعمل فيه كذا» (رسوم على فيديو قائم) | `motion-graphics` (+ `gallery-placement`) |
| «تعليق صامت» / «ريأكشن» | `silent-reaction` |
| «مونتاج ورقي» | `paper-montage` |
| «إعلان» | `advertising-video` |
| «قص من الثانية/الإطار كذا إلى كذا» | `segment-cut` (في أي وقت ولأي فيديو) |
| «رندر» | `remotion-render` |
| «اعتمد» / «انشر» | `approval` ثم `publishing` |
| «أنا خارج البيت» / «أعطني رابطاً» / «اعمل نفقاً» | `delivery-links` |
| غلاف | `thumbnail-design` |

## ما لا يُخلط
- «مونتاج … انتهى مونتاج» ليست نوع طلب: يقولها الشيخ **داخل التسجيل** للمونتير (`montage-orders`). ما يكتبه المستخدم في الرسالة تعليمات عادية تُسجَّل مهاماً بلا كلمة سر.
- طلب لم يُذكر هنا: أسأل بالنقر قبل البدء، ولا أخترع سلسلة.

## بوابة الموجّه
تمّ = سُمّيت السلسلة، وقُرئت القواعد العامة والشجرة، وبدأت أول مرحلة.
