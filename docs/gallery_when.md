# متى يُستعمل كل عنصر (تفصيل `MONTAGE_BRIEF.md` §8.8)
> المرجع الأعلى نص حقل «متى تستخدمه» في المعرض (`data/gallery_notes.json` حقل `when`، `node tools/element_usage.mjs list`)؛ هذا الجدول ملخّصه. `node tools/pick_triggers.mjs` (داخل `stage.mjs check`) يفشل إن مرّت لحظة عنصر بلا استعماله إلا بسبب في `skipPicks`/`skipMetaphors`.

## عناصر المواصفة الأساسية
| العنصر (النوع) | متى |
|---|---|
| `TornNote` (`torn`) | خلاصة مهمة من كلامه، جملة تامة؛ مرة في الدقيقة حداً أقصى |
| `WordScraps` (`scraps`) | كلامه المهم بنصه ≤ 7 كلمات؛ مرة في الدقيقة حداً أقصى |
| `BlurRise` (`blur`) | كلام المردود عليه، تحت شاشته |
| `KeyChip` (`word`) | عبارة في نصف الشاشة فقط |
| `TornPhoto` (`tphoto`) | كل شخص يُذكر باسمه (إلزامي)، عند أول ذكر |
| `PinnedPhoto` | عالِم يُستشهد به |
| `SourceWalk` / `PhotoFrame` | «هذا الرجل / هذا الشخص» ومن يُرد عليه |
| `StatRow` (`rows`) تحت `Banner` | البنود المعدودة، الأسئلة المتتالية، الشروط ونتائجها، وصف مهنة أو شيء |
| `CompareCards` | مقارنة (الراجح يميناً) |
| `ConvergeMerge` | أصل مشترك لعدة مصادر (يلزمه تقسيم) |
| `PanelToCanvas` | اختيار من قائمة |
| `TimelineTravel` (`timeline`) | سيرة ومراحل وتاريخ خلافة |
| `TimelineCounter` | أرقام متغيرة |
| التقويم (`date`) | كل تاريخ منطوق (يوم وشهر وسنة، أو سنة، أو قرن)، بالرقم والشهر الصحيحين |
| `pmap` | كل مدينة أو بلد أو انتقال |
| `PopCard` (`flag`) | علم دولة |
| `Clock` (`clock`) | وقت أو مدة |
| `DashArc` (`arc`) | شيئان أو شخصان بينهما علاقة |
| `stamp` | «هذا هو الراجح/الصحيح/الصواب» |
| `rewrite` | خطؤه في رقم أو كلمة |
| `news` | كل خبر: لقطة صفحته الرسمية |
| `scene` (المشهد الورقي) | أشخاص أو أشياء أو قصة |
| `tree` | كل تفرع (لا النسب وحده) |
| `PhoneChips` (`phone`) | فيديو طولي قصير يُرد عليه، أو ما يظهر على جوال |
| `SakugaMove` / `SpotlightCard` / `FlashCut` | عرض مصدر، بالتناوب |
| `CommentCard` | تعليق واحد في منطقة الكتابة |
| `BrushX` | شطب على صورة بإطار ممزق (حزب الله) |
| `shoe` | صورة بشار الأسد |
| `peek` | صورة تطلع من الزاوية السفلية اليسرى |
| `tvoff` | إطفاء الشاشة بأمره |
