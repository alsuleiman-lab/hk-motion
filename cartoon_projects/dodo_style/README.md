# مرجع وضعيات «دودو» السابق

لـ«عائلة دودو» ذات الشخصيات الست والمفاصل المتصلة استخدم `../dodo_family/manifest.json` و`../dodo_family/rig.ts`. هذه الحزمة تحتفظ بالوضعيات السابقة للمشاريع القائمة ودراسة الشكل.

الاسم المعتمد: **دودو (Dodo)**

نمط رسومي كرتوني فكاهي خفيف يعتمد على البساطة التعبيرية (Doodle Art) مع خطوط حبر سوداء عريضة ومظهر دافئ وجذاب.

---

## 🎨 الخصائص البصرية لاستايل «دودو»
1. **الرأس والملامح:** رأس دائري بلون خوخي هادئ، محدد بخط حبر عريض، تعابير كوميكية سريعة ومحببة.
2. **الجسد والأطراف:** جسم بسيط وأطراف خطية (Stick-style) سميكة ومستقرة، ترتكز بثبات على الأرض دون أي اهتزاز للجسم.
3. **التحريك الصوتي (Lip-Sync):** 
   - الفم ينفتح وينغلق تلقائياً بالتزامن مع مخارج الحروف ومقاطع الكلام أثناء حديث الشخصية.
   - الفم يبقى مغلقاً تماماً أثناء الإنصات والسكوت.
   - حركة مضغ وتبديل سريع أثناء تناول الطعام في المشاهد المناسبة.
4. **التمايز اللوني وتنوع الشخصيات:**
   - الشخصية الأساسية: قميص أزرق سماوي ودقن نظيف.
   - شخصية **«أبو اللحية»**: قميص أصفر ولحية سوداء كثيفة مع فم متزامن صوتياً داخل اللحية.
   - الشخصية الثانوية (البخيل الأصلي): قميص خردلي / زيتوني.
   - إمكانية إضافة تدرجات لونية أخرى لأي شخصيات إضافية.
5. **البيئة والإخراج:**
   - مشاهد طولية 9:16 ذات طابع شرقي كرتوني (بيوت طينية/حجرية، أروقة، أسواق، سفرة نحاسية).
   - شريط كابشن عربي متزامن كلمة بكلمة في المنطقة الآمنة العلوية.

## 📂 محتويات حزمة «دودو»
- `assets/`: تضم جميع الوضعيات الأساسية بصيغة PNG شفافة عالية الدقة مع نسختين لكل وضعية (فم مفتوح + فم مغلق).
  - `hands_up` (رفعة اليدين والتعجب)
  - `point_talk` (الإشارة والشرح)
  - `hands_hips` (وضع اليدين على الخصر / الوقوف الحازم)
  - `hands_folded` (تشبيك اليدين بأدب)
  - `shrug_spread` (فتح اليدين والاستغراب)
  - `hands_behind` (وضع اليدين خلف الرأس / الاسترخاء)
  - بالإضافة لنسخ الشخصية الثانوية `miser_*`.
- `components/DodoCharacter.tsx`: مكوّن التحريك الجاهز للاستخدام في أي مشروع Remotion.

---

## 🚀 الاستخدام في الكود
```tsx
import { DodoCharacter } from "../cartoon_projects/dodo_style/components/DodoCharacter";

<DodoCharacter
  frame={frame}
  pose="point_talk"
  x={330}
  y={1320}
  scale={1.4}
  isSpeaker={true} // يحرّك الفم تلقائياً مع الكلام ويثبّت الجسد
  theme="default"  // "default" للأزرق، أو "miser" للخردلي/الزيتوني
/>
```
