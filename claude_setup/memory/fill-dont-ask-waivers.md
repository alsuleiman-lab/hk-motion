On «GTA 6» (2026-11-20) I asked the user to approve five waivers (a number, «احذر يا أخي», a stream mention…) instead of filling them. He refused: «أنت بدك تضيف 150,000، حط عداد… احذر يا أخي، حط إشارة تحذير، ارسم إشارة تحذير… عبي عبي، لا تطلب. ليش تتكاسل؟ لازم تبني قبل الفحص… الفراغات تكون ممتلئة».

**Why:** a waiver request is laziness pushed onto the user. The gallery has a counter, and anything it lacks I can draw.

**How to apply:**
- Before any full check, the plan already fills every gap and every required item:
  - a number → the counter;
  - a warning → a warning sign;
  - spoken words → writing.
- Ask about a waiver only for a transcription error (a word he never said), and still prefer fixing the requirement over asking.
- See [[run-tasks-in-parallel]].
