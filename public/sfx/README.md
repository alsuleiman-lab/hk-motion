# Reusable sound effects (no music)
Generated by `tools/make_sfx.py` (python stdlib only). Copy this folder to any Remotion project's `public/`.
- whoosh.wav  scene transition (0.7s)
- pop.wav     element reveal (0.14s)
- chime.wav   lower-third / highlight (0.9s)
- tick.wav    small UI tick (0.05s)
Use at low volume (0.12-0.25) under the speech.
