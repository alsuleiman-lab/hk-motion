# مجلد البيرول الخاص (public/broll_lib)
صور وB-roll يقدّمها المستخدم لتُستعمل كخلفيات لمواضيع متكررة. لا تُحذف ولا تُنظَّف مع المشاريع.
- `religion_distorters/` (3 صور بدقة 1672×941: `distorters_1` لافتة «تكوين لتغيير صحيح الدين»، `distorters_2` مجموعة أشخاص، `distorters_podcast` طاولة بودكاست): تُعرض خلفية خلف الشيخ المعزول (وأول المقدمة بدل المخطوطة) كلما تكلم عن **الحملة لهدم الدين، أو الذين يحرّفون الدين أو يبدّلونه أو ينكرون السنة**؛ تُبدَّل بينها لا الثلاث معاً، ولا يتكرر الاختيار نفسه متتالياً. الوجوه النسائية فيها مطموسة أصلاً (لا تُنزع).
